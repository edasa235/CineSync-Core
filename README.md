# CineSync Core

Personal media server backend.

## Requirements

- Node.js 24+
- npm
- WSL 2 recommended on Windows

## Setup

Clone the repository:

git clone git@github.com:edasa235/CineSync-Core.git

cd CineSync-Core

Install dependencies:

npm install

Create environment file:

cp .env.example .env

## Development

Start development server:

npm run dev

Build:

npm run build

Start production build:

npm start
